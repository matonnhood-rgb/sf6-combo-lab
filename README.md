## 入力ノードエディタ

`アクション編集` 画面では、入力イベントをノード形式でも作成・編集できます。ノード1個は既存の `inputEvents` 1件に対応し、「そのFで押されているべきキー状態」を表します。
ノードで編集した内容は新しい保存形式ではなく、従来どおり `ActionDefinition.InputEvents` としてJSONへ保存されます。

画面上のフレーム表示は1F始まりです。内部処理とJSON保存は従来どおり0F始まりなので、画面の `1F` はJSONの `frame: 0`、画面の `5F` はJSONの `frame: 4` として扱います。既存JSONの `frame: 0` も画面では `1F` と表示されます。

方向はテンキー表記の `1` 〜 `9` を使います。`5` はニュートラルで、方向なしとして扱います。攻撃は `lp` / `mp` / `hp` / `lk` / `mk` / `hk` を使います。方向ボタンは現在ノードの方向を置き換え、攻撃ボタンは追加またはトグルで外します。

`236mp` のようなコマンド表記は1ノードには書かず、複数ノードに分けてください。

```text
1F: 2
3F: 3
5F: 6mp
```

従来の表編集も当面は残しています。ノードエディタと表は同じ `InputEvents` を編集するため、片方で編集した内容はもう片方にも反映されます。
